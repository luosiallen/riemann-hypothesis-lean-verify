Our first pass on this machine ran lean from a custom parallel scheduler without the --root flag that Lake passes. Lean then named modules src.Formalism.… instead of Formalism.…, so automatically generated instance names got a _src suffix where the sources expect, for example, _formalism. At about 100,000 modules this surfaced as one failure (OmPinsTr: unknown identifier …RatF_formalism), with 425 dependent modules blocked.

A wrong name can only make compilation fail; it cannot make the kernel accept a false proof. But the compiled files no longer matched a real Lake build, so we discarded all ~105,000 of them and restarted with -R src. Checked after the restart: 0 of the first 1,673 new files contain _src instance names. Progress below counts the new run only.
